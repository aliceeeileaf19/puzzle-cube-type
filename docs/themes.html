Themes

A cube shows a two-tone bitmap, so a theme is two sticker colours: --ct-off for the unlit sticker and --ct-on for the lit one. Eight face colours are derived from them. A light --ct-off also needs the four --ct-off-* ramp values, because a pale colour cannot be lifted further — the paper theme shows the override.

Default

/* nothing set */

Paper

--ct-off:#e7e6dd --ct-on:#14130f + 4 ramp values

Amber

--ct-off:#1a1205 --ct-on:#ffb000 --ct-ink:#ffb000

Lab

--ct-off:#080807 --ct-on:#f1eee5 --ct-ink:#f1eee5
